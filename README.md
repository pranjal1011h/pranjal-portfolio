# Pranjal Hingmire — Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio page
- `style.css` — design and animations
- `script.js` — typing, scroll and UI animations
- `assets/profile.png` — profile photo
- `assets/Pranjal_Resume.pdf` — resume used by the View Resume / Download CV buttons

## Run locally
Keep the folder structure unchanged and open `index.html` in a browser.

## Deploy
Upload the whole folder to GitHub or drag the folder to Netlify Drop.
