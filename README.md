# Pranjal Hingmire — Portfolio

Static HTML/CSS/JavaScript portfolio.

## Folder structure

- `index.html`
- `style.css`
- `script.js`
- `assets/profile.png`
- `assets/Pranjal_Resume.pdf`
- `assets/Bharat_Software_Labs_Internship_Offer_Letter.pdf`

## Add certificates

Place each certificate PDF inside `assets/`, then add its file link to the matching certification card in `index.html`.

Example:

```html
<a href="assets/your-certificate.pdf" target="_blank" rel="noopener">View Certificate ↗</a>
```

Do not rename the existing resume, profile photo, or offer-letter files unless you also update their paths in `index.html`.
